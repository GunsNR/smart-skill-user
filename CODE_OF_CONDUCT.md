# Code of Conduct

## Our Pledge

We want this project to be useful, practical, and welcoming.

## Standards

Good contributions are:

- respectful and specific
- grounded in real agent workflow needs
- free of private customer or workspace data
- honest about limitations

Unacceptable behavior includes harassment, doxxing, credential sharing, and knowingly adding private or harmful material.

## Enforcement

Maintainers may remove comments, issues, pull requests, or contributors that violate these standards.
