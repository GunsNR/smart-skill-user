## LinkedIn Post

I released Smart Skill User, an open-source preflight workflow for developers using AI coding agents across multiple projects.

The workflow asks the agent to confirm scope, identify the task type, choose the single best skill or smallest effective skill stack, skip irrelevant instructions, and apply approval gates before implementation.

It is useful when a repo has many instructions, examples, deployment notes, cleanup rules, or project-specific workflows. The point is not to starve the agent of context. The point is to load the right context at the right time.

Smart Skill User works with Codex, Claude Code, and AGENTS.md-compatible workflows.

## Reddit / Hacker News Post

I built Smart Skill User, a small open-source instruction workflow for AI coding agents.

The idea is straightforward: before an agent starts editing, it should run a short preflight and decide which instructions are actually relevant.

It asks the agent to confirm scope, classify the task, choose one best skill or the smallest effective skill stack, skip unrelated docs, and identify approval gates before risky actions.

It works through plain Markdown guidance for Codex, Claude Code, and AGENTS.md-compatible workflows. It does not hook into platform internals or promise measured token reductions. It is a practical workflow for reducing context bloat and wrong-scope edits.

Repo:
https://github.com/GunsNR/smart-skill-user
