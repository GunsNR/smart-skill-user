## Reddit / Hacker News Post

I made a small open-source project called Smart Skill User.

The idea is simple: before an AI coding agent starts editing, it should run a short preflight and decide what instructions it actually needs.

Smart Skill User asks the agent to:

- confirm repo/project scope
- classify the task
- choose the best single skill for narrow work
- choose the smallest effective skill stack for multi-part work
- skip unrelated skills and docs
- identify approval gates before risky actions

It works as plain Markdown guidance for Codex, Claude Code, and AGENTS.md-compatible coding agents. For Codex, it supports both user-level guidance and repo-level installs.

It does not hook into agent internals or guarantee token savings. It is a practical workflow for reducing context waste and wrong-scope edits.

Repo:
https://github.com/GunsNR/smart-skill-user

## Press / Speaking Points

- Smart Skill User is an independent open-source project.
- It is not affiliated with OpenAI, Anthropic, or GitHub.
- It works through plain instruction files and optional skill installs.
- The core behavior is a short preflight before implementation.
- The preflight confirms scope, classifies the task, and selects the right skill route.
- It is especially useful for multi-project workspaces and repos with many instructions.
- It emphasizes approval gates for deploys, connector changes, destructive cleanup, and visual/CRO commits.
- It is MIT licensed.
