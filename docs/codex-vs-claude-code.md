# Codex Vs Claude Code

Smart Skill User is designed to be portable, but install mechanics differ.

## Codex

Codex can use:

- repo guidance through `AGENTS.md`
- skill folders with `SKILL.md`
- user-level guidance and user-level skill folders

This repository includes a Codex skill at `skills/smart-skill-user/SKILL.md`.

## Claude Code

Claude Code commonly uses project guidance through `CLAUDE.md`.

This repository provides a compatible instruction template, not a claim of native Claude skill packaging. Use `templates/CLAUDE.md` as a portable preflight workflow.

## AGENTS.md-Compatible Agents

Any agent that reads repository instructions can use the generic preflight in `templates/smart-skill-preflight.md`.
