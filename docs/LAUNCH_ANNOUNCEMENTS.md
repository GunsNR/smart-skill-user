## GitHub Release Note Draft

Smart Skill User is an MIT-licensed preflight workflow for AI coding agents.

It helps Codex, Claude Code, and AGENTS.md-compatible workflows start with the right context:

- confirm repo/project scope
- identify task type
- choose the single best skill or smallest effective skill stack
- skip irrelevant skills and docs
- avoid loading every instruction by default
- apply approval gates before risky actions

This release includes:

- Codex user-level install guidance
- repo-level AGENTS.md install guidance
- Claude Code and generic AGENTS.md templates
- examples for UI, SEO, media, cleanup, deploy, and wrong-scope tasks
- validation tests and privacy checks
- optional report-only auto-research docs
- support, quick-start, and launch announcement docs

## LinkedIn Announcement

I released Smart Skill User, a small open-source project for developers using AI coding agents across multiple repos.

The idea is simple: before an agent starts implementation, it should not load every instruction by default. It should first decide what context is actually useful.

Smart Skill User adds a short preflight:

- confirm repo/project scope
- identify the task type
- choose the single best skill or smallest effective skill stack
- skip irrelevant skills and docs

## Reddit / Hacker News Announcement

I built Smart Skill User, an open-source instruction workflow for AI coding agents.

It is based on a small habit that helps in multi-project AI coding work: before editing, the agent should run a preflight and choose the right instructions instead of reading everything.

The workflow asks the agent to:

- confirm scope
- classify the task
- choose one best skill for narrow work
- choose the smallest effective skill stack for multi-part work
- skip unrelated skills
- avoid unnecessary file reads and searches
- identify approval gates before risky actions

It supports Codex, Claude Code, and generic AGENTS.md workflows.

The project is intentionally small: one core skill, install templates, examples, docs, validation tests, and safety guidance.
