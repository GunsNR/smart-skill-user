# Security Policy

## Reporting

Please open a private security advisory if your hosting platform supports it, or contact the maintainers through the repository owner profile.

## Scope

Smart Skill User is an instruction workflow. It does not enforce operating system permissions, network controls, or deployment permissions by itself.

Security-sensitive contributions should preserve these principles:

- never expose secrets or private data
- require explicit approval before destructive or production-impacting work
- avoid live connectors unless required by the task
- prefer targeted reads over broad scans
- stop when scope is unclear
