# Install For Generic AGENTS.md Workflows

Smart Skill User works with agents that read `AGENTS.md` or similar repository instructions.

## Steps

1. Open your repository `AGENTS.md`.
2. Paste the content from `templates/smart-skill-preflight.md`.
3. Add project-specific scope rules.
4. Keep approval gates explicit.

## Compatibility

This instruction pack is intentionally plain Markdown. It should work with any coding agent that respects repository guidance, even if that agent does not support Codex skills.
