# Install For Claude Code

Smart Skill User can be used with Claude Code as a portable instruction pack.

This repository does not claim native Claude skill packaging. Instead, copy the preflight workflow into your project `CLAUDE.md`.

## Steps

1. Open or create `CLAUDE.md` at your project root.
2. Copy the relevant content from `templates/CLAUDE.md`.
3. Keep the workflow concise and project-specific.
4. Ask Claude Code to run Smart Skill Preflight before work.

## Recommended Use

Use Smart Skill User when your project has multiple instruction sets, clients, surfaces, or approval gates. It helps Claude Code decide what to read before it reads too much.
