# Example: Mobile Hero Task

## User Prompt

> Update the mobile homepage hero.

## Smart Skill Preflight

```text
Scope: unclear: confirm repo, client/project, homepage, and mobile breakpoint before editing.
Task type: UI/design/CRO and copy.
Selected skill stack: visual-quality for layout polish; CRO review for conversion impact; copy/local SEO if headline or CTA changes.
Why this stack: one skill is not enough because the task spans responsive layout, conversion, and message quality.
Skipped skills: deployment, database, connector tools.
Approval needed: yes, preview before commit.
Planned validation: responsive preview, screenshot review, and relevant UI checks.
```

## Result

The agent asks for scope if multiple sites exist. After scope is confirmed, it automatically routes the task to the smallest effective skill stack and reads only the relevant homepage files and design guidance.
